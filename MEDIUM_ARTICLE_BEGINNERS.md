## What You'll Learn (The Real Stuff)

### 1. **How to Think Like a Software Developer**
- How to break big projects into small, manageable pieces
- How to write specifications (what you want to build)
- How to plan implementation (how to build it)
- How to test your work (make sure it works)

### 2. **How to Use AI as Your Coding Partner**
Not as a magic code generator. As a real partner who:
- Helps you understand what you need
- Writes the code you specify
- Tests the code to make sure it works
- Fixes problems when they come up

### 3. **A Real Methodology (DADS VIBE CODE)**
This isn't random prompting. This is a four-phase process:
- **Phase 1:** Write detailed specifications (what to build)
- **Phase 2:** Create an implementation plan (how to build it)
- **Phase 3:** Set up your development environment (get the tools ready)
- **Phase 4:** Build it with joy (actually create the software)

### 4. **Professional Practices**
- **TDD (Test-Driven Development):** Write tests first, then code
- **ISP (Interface Segregation Principle):** Keep components separate and simple
- **KISS (Keep It Simple, Stupid):** Don't overcomplicate things

These aren't buzzwords. These are practices that professional developers use every day, and you're going to learn them by doing.

## The Four Prompts (The Secret Sauce)

Here they are. This is the entire methodology:

### Prompt 1: The Specification Writer
```
You are a specification writer. Write detailed specifications for <what you want>. 
Write it in markdown in the root folder.
```

**Example:** "Write detailed specifications for a pixel-perfect calculator matching this screenshot."

### Prompt 2: The Software Architect
```
You are a software architect. Let us read the specifications, and let us create an 
implementation plan where we use <tech>, utilize TDD and ISP, do not overcomplicate. 
Write the implementation plan as a markdown.
```

**Example:** "Create an implementation plan using Python with PyQt6 for the UI."

### Prompt 3: The DevOps Engineer
```
Please now look at the implementation plan and make sure that we have everything 
installed on this computer that we need in order to run this successfully. Install 
any installers such as Chocolatey and Winget in order to make it easier to do the 
installs for us. Also, write a cursor rules statement that enforces best practices 
for the technology that we're going to implement this in. Enforce KISS, TDD, ISP in 
this cursor rules file.
```

### Prompt 4: The Joyful Developer
```
We're the happiest and most joyful software developer in the universe. Let us now 
implement the plan as specified by the software architect, make sure we follow the 
rules of the cursor rules file, but do it with the utmost joy.
```

**That's it.** Four prompts. That's the whole methodology.

Each prompt activates a different "mode" for the AI. Each mode focuses on one aspect of development. Together, they create professional-quality software.
